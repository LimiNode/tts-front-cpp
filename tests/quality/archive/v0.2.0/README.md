# v0.2.0 quality archive

These files are the immutable 352-case corpus and strict snapshot used for the
`v0.2.0` release. They were archived from release baseline commit
The corpus/snapshot were captured in quality-baseline commit
`f6203d1` for the released `v0.2.0` implementation
`77a0c04138b367342f375dcf7050ce4e193e2bef`; they are intentionally not
regenerated by the current quality-corpus generator.

To audit this exact release data, use the release checkout and replace the active
quality inputs with these two files, or run the audit tool against a harness that
loads this directory. The evolving post-release corpus remains at
`tests/quality/en_ru_sentences.tsv` and is documented separately.
